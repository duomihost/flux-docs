# 订阅下载或更新失败

先确认自己使用哪类客户端，再按对应步骤处理。每次只改变一个条件；成功后停止排查。更新失败时保留已有配置和错误提示，不要反复删除订阅或重置个人订阅地址。

## Paxora 官方客户端没有同步到节点

官方客户端登录后自动同步账号与节点，不需要手动粘贴订阅地址。

1. 断开连接，确认本地网络正常；断开后也不能上网时，先处理本地网络，暂不继续订阅排查。
2. 在用户中心确认套餐有效、仍有可用流量。账号或权限显示异常时，通过[客服或工单](../support/contact.md)核查。
3. 刷新节点列表；没有刷新入口时，完全退出客户端后重新打开一次。
4. 仍为空或同步报错时，记录客户端版本、发生时间和错误提示，按[订阅问题模板](../support/feedback.md#订阅下载或更新问题模板)反馈。不要改用其他人的账号或订阅。

## 第三方客户端无法下载或更新订阅

1. 保留当前配置；客户端支持备份时，可先备份自己的规则和设置。备份可能包含凭据，请只保存在可信位置。
2. 从[用户中心](../support/contact.md#官网及相关入口)重新核对个人订阅选项，选择适合当前客户端的格式。不要复制登录页面地址、教程链接或下载其他软件的链接。
3. 确认粘贴完整，没有额外空格或换行；重置过订阅时，重新获取当前地址。不要手改地址的域名、路径或凭据。
4. 仅保留当前需要的代理客户端，检查是否存在[代理冲突](./proxy-conflict.md)。本地网络正常且设备允许切换时，可更换一个网络后重试一次，比较结果即可。
5. 根据下面的报错分支处理；仍不成功时停止重复请求并提交反馈。

订阅 01 无法下载时，可按[主、备用地址说明](../subscription/overview.md#numbered-addresses)选择一个备用地址重试，不必连续遍历全部地址。如果订阅已更新、节点也出现，但 Shadowrocket 仍无法连接，请确认所选页面要求的[模块已先导入](../subscription/import-subscription.md#shadowrocket-module)。

不要将个人订阅粘贴到在线测速、转换或“订阅检测”网站，也不要关闭证书校验来绕过下载错误。

## 按错误提示缩小范围

| 现象 | 下一步 |
| --- | --- |
| 超时、连接失败或无法解析域名 | 先确认本地网络；有条件时仅换一个网络对比。若普通上网正常而订阅仍失败，保留时间与错误后反馈。 |
| `401` / `403` 或提示无权限 | 核对账号状态和当前个人订阅，尤其确认是否重置过地址。单凭状态码不能断定套餐过期，不要连续重试或反复重置。 |
| `404` / `410` 或资源不存在 | 重新从用户中心获取当前订阅；同一当前地址仍报错时反馈，不猜测或遍历其他路径。 |
| `429` 或提示请求过于频繁 | 停止手动连点和高频自动更新；按客户端提示等待，有问题时记录提示再反馈。 |
| 证书或 TLS 错误 | 核对系统日期、时间与时区；不要忽略证书错误或安装来源不明的证书。仍失败时反馈。 |
| 返回登录页面、HTML 或配置格式错误 | 核对是否误复制了网页地址，以及订阅格式是否适配客户端。无法确认时记录客户端名称与报错，不把完整订阅或响应内容公开。 |
| 更新成功但节点为空 | 核对套餐和可用流量、客户端格式及是否选错配置；仍为空时反馈，不凭空补写节点。 |

节点列表已经正常更新，但连接仍然失败时，转到[无法连接](./cannot-connect.md)；能够连接但速度不理想时，查看[速度慢](./slow-speed.md)。

## 什么时候停止排查

完成一次地址与格式核对、一次更新，以及条件允许时的一次网络对比后，仍然出现同样错误，就按[订阅问题模板](../support/feedback.md#订阅下载或更新问题模板)反馈。账号权限、证书异常或请求频率提示应优先按对应分支处理，不需要做完所有尝试。

反馈中只写订阅选项名称、客户端和错误提示；截图遮住完整 URL、二维码、邮箱与凭据。不要提交订阅正文、密码或完整配置文件。
