# 代理冲突

如果系统中同时运行多个代理或 VPN 工具，可能出现无法连接、网页打不开或断开后仍受代理影响。

处理方式：

1. 退出其他代理软件。
2. 关闭浏览器代理插件。
3. 检查系统代理设置。
4. 完全退出并重新打开 Paxora。
5. 重新连接节点。

如果使用的是第三方客户端，也应避免同时打开 Paxora。排查时只保留当前需要测试的一个客户端。

## 浏览器单独无法代理

如果其他应用或浏览器可以正常访问，只有某个浏览器异常，可以按以下顺序缩小范围：

1. 在另一个浏览器中打开同一网址，确认问题是否只发生在原浏览器。
2. 在原浏览器中打开无痕或隐私窗口，再访问同一网址。Chrome 在 Windows 上的快捷键为 `Ctrl + Shift + N`，在 macOS 上为 `Command + Shift + N`。
3. 如果隐私窗口正常，逐个停用代理、VPN 或网络过滤类扩展，每停用一个就重新测试。
4. 检查浏览器是否设置了独立代理，或受到公司、学校的管理策略控制。受管理的设备应联系管理员核实。
5. 如果不同浏览器都无法访问，返回[无法连接](./cannot-connect.md)继续排查本地网络、套餐和节点。

隐私窗口仍可能运行获准在该模式下使用的扩展，不能仅凭一次测试排除扩展冲突。排查时保留客户端连接和节点不变，无需关闭系统防火墙或卸载安全软件。
