# 流量显示异常

客户端显示的流量可能包含上传和下载，也可能因为统计同步存在短暂延迟。浏览器后台播放、系统更新、云盘同步和其他设备使用同一账号，都会消耗流量。

## 先这样检查

1. 断开 Paxora 或第三方客户端。
2. 关闭下载、视频、云盘同步和系统更新。
3. 确认没有其他设备正在使用同一订阅。
4. 等待几分钟后刷新账号或重新登录，查看统计是否同步。
5. 重新连接后观察短时间内的变化。

如果流量在未连接时仍持续明显增长，请及时重置个人订阅，并联系客服核查。提供截图时不要显示完整订阅地址、邮箱或其他隐私信息。
