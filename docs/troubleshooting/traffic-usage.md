# 流量显示异常

客户端实时速率、客户端累计流量和用户中心的套餐扣除量，可能采用不同的统计范围，也可能存在同步延迟。比较数据时，应确认统计的是同一时段，并查看上传、下载和[节点倍率](../nodes/choose-node.md#节点倍率如何影响流量)的计算口径。

不要将某个固定倍数作为所有客户端和套餐的通用换算规则。套餐扣除方式以当前套餐及用户中心说明为准。

节点卡片未显示倍率时，不要自行按 `1×` 计算。节点时段倍率与统一时段计费规则也可能不同，详见[倍率说明](../nodes/choose-node.md#节点倍率如何影响流量)。

## 先这样检查

1. 断开 Paxora 或第三方客户端。
2. 关闭下载、视频、云盘同步和系统更新。
3. 确认没有其他设备正在使用同一订阅。
4. 等待几分钟后刷新账号或重新登录，查看统计是否同步。
5. 重新连接后观察短时间内的变化。

## 检查后台程序与其他设备

浏览器后台播放、系统更新、云盘同步、下载任务，以及其他设备使用同一账号，都可能消耗流量。还应根据使用环境检查：

- **路由器代理**：是否还有其他家庭设备通过路由器连接节点。
- **Docker、虚拟机或其他子系统**：是否存在独立运行的下载、镜像拉取或同步任务。
- **局域网共享与端口转发**：是否允许其他设备使用代理，访问范围是否符合预期。

检查时优先暂停相关任务或关闭不需要的代理共享，不要直接删除网络配置或关闭防火墙。

## 对照流量明细

如果用户中心提供流量明细，请记录异常发生的时间段和时区，并与当时的设备使用情况、已公布的倍率规则及客户端记录对照。保留观察前后的数值和时间，避免用实时速率与累计扣除量直接比较；也不要用当前卡片上的倍率反推过去整段时间的扣除量。

若所有已知设备均已断开，等待统计同步后流量仍持续明显增长，或确认订阅已经泄露，请及时[重置个人订阅](../subscription/security.md)并联系客服核查。重置后，请在各台设备上重新获取并导入订阅。

## 联系客服时提供什么

- 异常时间段及所在时区。
- 观察前后的套餐流量数值或流量明细截图。
- 设备、客户端版本，以及使用的节点名称和倍率（如有标注）。
- 已暂停的后台任务、已断开的设备及观察结果。

提交截图或日志前，请遮住邮箱、完整订阅地址、二维码和其他个人信息，不要提交账号密码或完整配置文件。
