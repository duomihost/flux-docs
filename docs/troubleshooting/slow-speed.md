# 速度慢

速度慢可能来自本地网络、运营商线路、节点负载或目标网站限制。

## 按顺序比较

1. 先暂停下载、云盘同步和其他占用带宽的任务。断开代理后，确认日常上网是否也明显变慢；本地网络本身异常时，先处理本地网络，不继续消耗流量测速。
2. 确认节点列表可以正常更新。Paxora 官方客户端刷新节点，第三方客户端更新订阅；更新失败时先看[订阅下载或更新失败](./subscription-failed.md)。
3. 保持设备、网络、目标服务和代理模式不变，只切换一至两个账号可用的节点，分别记录实际表现。延迟可辅助选择，但不能单独作为速度结论。
4. 如果只有一个应用或网站慢，而其他访问正常，记录具体应用、目标服务和时间；问题不一定来自节点。如果只有某个浏览器异常，先看[浏览器单独无法代理](./proxy-conflict.md#浏览器单独无法代理)。

不必为了得到“最高速度”连续测速。测速和视频播放可能消耗套餐流量；订阅地址编号、节点倍率或一次延迟结果都不能推算固定 Mbps。

## 什么时候反馈

普通上网正常、已排除后台占用，并对比少量节点后仍然慢，就停止重复测试，按[连接问题反馈模板](../support/feedback.md#连接问题反馈模板)提交时间与时区、运营商、节点、受影响服务和对比结果。间歇性问题可记录出现时段，无需一直保持测试。
