# 更新日志总览

按发布日期记录，最新的在最上面，每期列出各平台完整版本号（最后一段按平台各自计数）。「全平台」为各平台共有的改动，其余小节只写该平台独有的改动。按平台查看：[Windows](./windows.md) · [macOS](./macos.md) · [Android](./android.md) · [iOS](./ios.md)。

## 2026.1008

**2026.10.08**

版本：macOS 2026.1008.1005 Beta

### macOS

- 新增「动态」：近期公告、软件版本与更新记录，铃铛显示未读红点。
- 新增分组连接：按分流规则分组分别选择节点。
- 代理模式新增「直连」，与规则、全局并列。
- 新增网络修复工具，一键清理残留的代理设置。
- 新增设置备份与恢复，设置可通过局域网发送到电视端。
- 注册页增加服务条款确认与语言切换；服务条款、隐私政策改为打开官网页面。
- 工具页与连接页工具栏重新排版；外观设置可关闭装饰边框。
- 订阅刷新与节点列表加载更稳定，订阅失败原因提示更清楚。
- 修复 macOS 13 / 14 上虚拟网卡无法启动。
- 新增虚拟网卡 IPv6 开关；从 Dock 可重新打开已隐藏的窗口；连接中退出前会确认。

## 2026.1006

**2026.10.06**

版本：Windows 2026.1006.0984

### Windows

- 虚拟网卡改由安装包注册的系统服务驱动，减少重复的管理员授权；优化服务校验、通信与停止流程，升级时自动清理旧版任务及残留文件。
- 新增分组连接，可按服务或分流类别分别选择节点，支持选择其他订阅通道的节点，并查看各分组实际使用的节点。
- 代理模式新增「直连」；直连模式下自动刷新本机 IP 和地区信息。
- 新增网络修复工具，清理残留的代理设置；连接前增加网络设置冲突提示。
- 新增设置备份与恢复；局域网共享支持账号密码；可配置关闭窗口时的行为，连接中退出前会确认。
- 新增「动态」与未读提醒，可查看公告和软件更新记录；更新前可查看本次更新说明。
- 优化节点列表加载、后台刷新与失败重试，展开节点时显示国家或地区旗帜；订阅刷新和域名解析更稳定，失败原因提示更清楚。
- 优化自定义规则分类，同一服务的规则合并展示，与分组连接保持一致。
- 注册页增加服务条款确认与语言切换，并根据服务端要求提示邮箱后缀、邮箱验证和邀请码；服务条款与隐私政策统一打开官网页面。
- 修复退出账号后残留部分界面状态和设置的问题；支持确认后退出当前设备登录，优化设备数量限制及登录失效提示。
- 优化套餐信息展示，长期套餐明确显示「长期有效」与「不重置」；新增账号邮件偏好及流量提醒设置指引。
- 优化工具页与连接页布局，外观设置可关闭装饰边框；完善语言切换与界面翻译。
- 优化启动诊断与错误提示，减少重复弹窗；上传诊断日志时可补充问题描述。
- 修复断开连接或退出应用后偶发残留后台进程的问题。

## 2026.0904

**2026.09.04**

版本：Windows 2026.0904.0811 · macOS 2026.0904.0809 · Android 2026.0904.0809

### 全平台

- 购买套餐可直接打开网站套餐页，多个地址自动切换。

### Windows

- 修复提权组件在应用退出后残留；修复内置浏览器初始化失败时无法回退。

### macOS

- 修复启动时残留旧核心进程；不再弹出钥匙串授权。

### Android

- 修复局域网来源被误拦截；停止连接不再卡住。
