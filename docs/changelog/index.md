# 更新日志总览

按发布日期记录，最新的在最上面，每期列出各平台完整版本号（最后一段按平台各自计数）。「全平台」为各平台共有的改动，其余小节只写该平台独有的改动。按平台查看：[Windows](./windows.md) · [macOS](./macos.md) · [Android](./android.md) · [iOS](./ios.md)。

## 2026.1017

**2026.10.17**

版本：macOS 2026.1017.1028 · Android 2026.1017.1027

### macOS

- 新增「动态」，集中查看近期公告、软件版本与更新记录，并显示未读提醒。
- 新增分组连接，可按分流类别分别选择节点；代理模式新增「直连」。
- 新增网络修复工具，清理残留代理设置并显示修复进度，完成后不再自动连接节点。
- 新增设置备份与恢复，支持通过局域网将设置发送到电视端；局域网共享支持账号密码。
- 优化虚拟网卡安装与授权引导，首次使用时分步提示安装网卡助手和允许系统扩展。
- 网卡助手支持在应用内卸载；删除主程序后，助手可自动清理残留组件。
- 修复 macOS 13 / 14 上虚拟网卡无法启动的问题；新增虚拟网卡 IPv6 开关。
- 修复更新后开机自启被系统拦截、断开连接后状态未及时更新及修改设置后意外重连的问题。
- 优化订阅刷新、节点列表加载和域名解析失败后的恢复，失败原因提示更清楚。
- 从 Dock 可重新打开隐藏窗口，连接中退出前增加确认；系统扩展授权与登录项显示品牌名称和图标。
- 优化工具页、连接页与设置弹窗布局，外观设置可关闭装饰边框；设置页明确标注正式版或 Beta。
- 注册页增加服务条款确认与语言切换，服务条款和隐私政策统一打开官网页面。

### Android

- 新增 32 位 ARM（armeabi-v7a）正式安装包，支持 Android 7.0 及以上、采用该架构的老款手机、平板和电视设备；同时提供 arm64-v8a 与 x86_64 版本。
- 更新按设备架构分别分发，减少下载到不匹配安装包的问题。
- 新增「动态」，集中查看近期公告、软件版本与更新记录，并显示未读提醒。
- 新增分组连接，可按分流类别分别选择节点；代理模式新增「直连」。
- 新增设置备份与恢复；局域网共享支持账号密码。
- 优化订阅刷新、节点列表加载及域名解析失败后的恢复，失败原因提示更清楚。
- 优化本地代理端口分配，减少与其他代理应用的端口冲突；升级后自动检查并修复不完整的分流数据。
- 完善 16 KB 内存页设备的兼容性，优化系统状态栏、连接页和工具页布局。
- 修复连接初期偶发误报网络不可用的问题，连接就绪后自动复查网络状态。
- 设置页明确标注正式版或 Beta，上传诊断日志时可补充问题描述。

## 2026.1009

**2026.10.09**

版本：macOS 2026.1009.1022 Beta

### macOS

- 修复 App 更新后开机自启被系统拦下、无法自动启动的问题。
- 修复断开连接未完全停止时仍按已连接处理、改设置后自动连回原节点的问题。
- 系统扩展授权弹窗与登录项改为显示品牌名称和图标，网卡助手名称随界面语言显示。
- 分组连接在全局、直连模式下提示「仅规则模式生效」，不再误显示「已保存」。
- 设置页「代理 IPv6 流量」未开启虚拟网卡模式时，点击会说明原因。
- 局域网共享认证改为独立一行，设置用户名密码的弹窗更紧凑。
- 一键修复网络环境新增进度动画，修复完成后不再自动连回原节点。
- 「动态」页更新记录标注 Beta，软件版本行显示完整版本号。
- 设置页「关于」显示 Beta 标签，不再使用窗口角标。
- 上传诊断日志弹窗改为更正式的措辞。
- 修复部分网络下服务器域名解析失败后无法恢复的问题。

## 2026.1006

**2026.10.06**

版本：Windows 2026.1006.0984

### Windows

- 虚拟网卡改由安装包注册的系统服务驱动，减少重复的管理员授权；优化服务校验、通信与停止流程，升级时自动清理旧版任务及残留文件。
- 新增分组连接，可按服务或分流类别分别选择节点，支持选择其他订阅通道的节点，并查看各分组实际使用的节点。
- 代理模式新增「直连」；直连模式下自动刷新本机 IP 和地区信息。
- 新增网络修复工具，清理残留的代理设置；连接前增加网络设置冲突提示。
- 新增设置备份与恢复；局域网共享支持账号密码；可配置关闭窗口时的行为，连接中退出前会确认。
- 新增「动态」与未读提醒，可查看公告和软件更新记录；更新前可查看本次更新说明。
- 优化节点列表加载、后台刷新与失败重试，展开节点时显示国家或地区旗帜；订阅刷新和域名解析更稳定，失败原因提示更清楚。
- 优化自定义规则分类，同一服务的规则合并展示，与分组连接保持一致。
- 注册页增加服务条款确认与语言切换，并根据服务端要求提示邮箱后缀、邮箱验证和邀请码；服务条款与隐私政策统一打开官网页面。
- 修复退出账号后残留部分界面状态和设置的问题；支持确认后退出当前设备登录，优化设备数量限制及登录失效提示。
- 优化套餐信息展示，长期套餐明确显示「长期有效」与「不重置」；新增账号邮件偏好及流量提醒设置指引。
- 优化工具页与连接页布局，外观设置可关闭装饰边框；完善语言切换与界面翻译。
- 优化启动诊断与错误提示，减少重复弹窗；上传诊断日志时可补充问题描述。
- 修复断开连接或退出应用后偶发残留后台进程的问题。
