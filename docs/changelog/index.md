# 更新日志总览

按发布日期记录，最新的在最上面。版本号最后一段按平台各自计数，同一天发布的各平台包尾号不同。「全平台」为各平台共有的改动，其余小节只写该平台独有的改动。按平台查看：[Windows](./windows.md) · [macOS](./macos.md) · [Android](./android.md) · [iOS](./ios.md)。

## 2026.0928

**2026.09.28**

### 全平台

- 新增「动态」：近期公告、软件版本与更新记录，铃铛显示未读红点。
- 新增分组连接：按分流规则分组分别选择节点。
- 代理模式新增「直连」，与规则、全局并列。
- 新增网络修复工具，一键清理残留的代理设置。
- 新增设置备份与恢复，设置可通过局域网发送到电视端。
- 注册页增加服务条款确认与语言切换；服务条款、隐私政策改为打开官网页面。
- 工具页与连接页工具栏重新排版；外观设置可关闭装饰边框。
- 订阅刷新与节点列表加载更稳定，订阅失败原因提示更清楚。

### Windows

- 虚拟网卡改由随安装包注册的系统服务驱动，不再反复弹出管理员授权。
- 修复断开连接后偶发残留后台进程。

### macOS

- 修复 macOS 13 / 14 上虚拟网卡无法启动。
- 新增虚拟网卡 IPv6 开关；从 Dock 可重新打开已隐藏的窗口；连接中退出前会确认。

### Android

- 局域网共享支持账号密码；多次重连更稳定；适配 16 KB 内存页设备。

### iOS

- 新增局域网共享、按需连接，设置可发送到电视端。

## 2026.0904

**2026.09.04**

### 全平台

- 购买套餐可直接打开网站套餐页，多个地址自动切换。
- 新增内容过滤：广告拦截与成人内容拦截独立开关。
- 分流规则支持按类别分组查看。
- 节点连接失败后自动重新拉取订阅；订阅改为多地址并发拉取，弱网下更快。
- 新增诊断日志上传（需确认），失败提示更易读。
- 新增 Paxora 网盘与帮助中心入口。

### Windows

- 修复提权组件在应用退出后残留；修复内置浏览器初始化失败时无法回退。

### macOS

- 修复启动时残留旧核心进程；不再弹出钥匙串授权。

### Android

- 修复局域网来源被误拦截；停止连接不再卡住。

## 2026.0818

**2026.08.18**

### 全平台

- 账号设备数量限制生效，被移除的设备会收到明确提示。
- 更新下载进度在各处可见；新增测试版通道；更新下载地址支持多个自动切换。
- 配置域名切换更快，弱网下超时更合理。
- 节点右键菜单支持单节点测速；延迟测试按分组独立进行。
- 私有域名解析按订阅通道独立，解析失败自动隔离。

### Windows

- 虚拟网卡授权不再依赖 VBScript；核心进程按所属应用精确回收。

### macOS

- 虚拟网卡授权提示显示品牌名称。

### Android

- 连接准备各步骤限时，授权前置，避免长时间停在「连接中」。

### iOS

- 首个内部测试版本。
