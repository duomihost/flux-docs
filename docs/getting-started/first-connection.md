# 首次使用 Paxora

本页适用于 Windows、macOS 和 Android 版 Paxora。

## 1. 登录账号

打开 Paxora，输入注册邮箱和密码登录。首次登录时，客户端需要同步账号、套餐和节点，加载时间可能比平时更长。

如果长时间没有显示节点，请完全退出 Paxora 后重新打开。

## 2. 选择节点

1. 打开节点列表。
2. 选择需要的国家或地区。
3. 优先选择延迟较低且状态正常的节点。
4. 确认首页已经显示所选节点。

如果不知道如何选择，可以先使用客户端推荐的节点。

## 3. 开始连接

点击“快速连接”或“连接”，等待状态变为“已连接”。首次连接时，系统可能要求授权 VPN 或网络配置，请按系统提示允许。

## 4. 测试连接

打开浏览器访问常用网页。如果网页可以正常打开，说明连接已经生效。

## 5. 断开连接

不再使用时，返回 Paxora 点击“断开连接”。确认状态变为“未连接”后再退出客户端。

:::tip
同一时间只运行一个代理或 VPN 客户端。多个客户端同时开启容易造成系统代理冲突。
:::
