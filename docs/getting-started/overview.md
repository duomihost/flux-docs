# 客户端选择

:::info
教程图片可能来自较早版本，按钮位置会随客户端更新变化。当前产品名称统一为 **Paxora**。
:::

## 选择客户端

- **Windows、macOS、Android 和 Linux**：优先使用 [Paxora 定制客户端](/docs/custom-clients)，登录后自动同步套餐和节点。Linux 的系统与架构要求见[安装教程](../installation/linux.md)。
- **iPhone / iPad**：使用 [Shadowrocket](../third-party/ios-shadowrocket.md)等兼容的第三方客户端，手动导入个人订阅。
- **路由器**：在 Paxora 定制客户端分类中查阅[OpenWrt / Merlin 插件教程](../third-party/router-openwrt-merlin.md)。
- **其他兼容客户端**：按设备平台查阅[第三方客户端教程](/docs/third-party-clients)。

## 各个入口有什么用途

| 入口 | 适合处理的事情 |
| --- | --- |
| [官网与用户中心](../support/contact.md#官网及相关入口) | 查看当前账号、套餐、可用流量和个人订阅，提交工单；具体状态以登录后显示为准。 |
| Paxora 官方客户端 | 登录账号、同步节点、建立或断开连接。 |
| 第三方客户端 | 导入个人订阅并连接节点，具体操作按对应平台教程进行。 |
| [技术文档](../intro.md) | 查安装步骤、订阅操作、排障和反馈方法；文档不能代替账号状态查询。 |

还未安装时先看[下载页面](./download.md)；已经安装则按[首次连接](./first-connection.md)操作。账号、订单或个人权限需要核查时，使用[客服与工单入口](../support/contact.md)。

## 使用 Paxora 官方客户端

Windows、macOS、Android 和 Linux 用户按以下流程操作：

1. 从[下载页面](./download)获取适合设备的 Paxora 安装包。
2. 安装并启动 Paxora。
3. 使用注册邮箱和密码登录。
4. 等待客户端自动加载套餐和节点。
5. 选择一个节点并点击“快速连接”或“连接”。
6. 页面显示已连接后，打开浏览器测试网络。

Paxora 官方客户端不需要手动导入订阅。

## 使用第三方客户端

iPhone、iPad 或希望使用兼容客户端的用户需要：

1. 安装对应的第三方客户端。
2. 登录用户中心并复制个人订阅地址。
3. 在客户端中导入订阅。
4. 选择节点并开启连接。

:::danger
订阅地址包含你的使用权限。不要分享给他人，也不要发布到群聊、截图或公开网站。
:::
