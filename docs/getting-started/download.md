# 下载客户端

## Paxora 官方客户端

Windows、macOS 和 Android 安装包目前放在统一的官方下载目录中：

- [官方下载目录](https://vault.digitalage.services/index.php/s/E8srJpTGLgQNzW7)
- [备用下载目录](https://vault.paxoras.com/index.php/s/E8srJpTGLgQNzW7)

进入目录后，根据设备选择文件：

| 设备 | 文件类型 | 下一步 |
| --- | --- | --- |
| Windows 10 / 11 | `.exe` | [查看 Windows 教程](../installation/windows) |
| macOS | `.dmg` | [查看 macOS 教程](../installation/macos) |
| Android / HarmonyOS | `.apk` | [查看 Android 教程](../installation/android) |

macOS 用户应先点击屏幕左上角 Apple 菜单，选择“关于本机”，确认 Mac 使用 Apple 芯片还是 Intel 芯片，再下载对应安装包。

## iPhone / iPad

Paxora 暂未提供 iOS 官方客户端。请从 App Store 安装 Shadowrocket：

- [Shadowrocket 使用教程](../third-party/ios-shadowrocket)

第三方客户端需要手动导入个人订阅地址。

:::warning
请只使用官方提供的下载目录、软件官方仓库或 App Store。不要安装来源不明的修改版客户端。
:::
