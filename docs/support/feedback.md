# 问题反馈指南

反馈前，请先参阅[常见问题](/docs/faq)，完成与问题现象对应的排查。仍未解决时，通过[客服或工单渠道](./contact.md)提交信息。

## 连接问题反馈模板

反馈无法连接、速度慢或特定网站访问异常时，建议按以下格式提供信息：

```text
设备与系统版本：
客户端名称与版本：
所在地区与运营商：
网络类型：家庭宽带 / 移动网络 / 公司或校园网络
节点名称与地区：
代理模式：规则 / 全局 / 其他（请说明）
受影响的网站或应用：
问题现象与错误提示：
发生时间与时区：
出现频率：持续发生 / 间歇发生（请说明频率）
已尝试的排查步骤及结果：
```

请尽量提供可复现的操作步骤，并说明问题影响单个节点、部分节点还是全部节点。对比不同节点或网络时，每次只改变一个条件，便于判断影响因素。

截图只需包含与问题有关的界面。提交前请遮住邮箱、个人订阅地址、二维码、验证码和订单支付信息；不要提交账号密码或完整配置文件。

## 流量异常反馈

涉及套餐流量扣除或统计差异时，请同时记录观察前后的流量数值、时间段、节点倍率（如有标注），以及已暂停的后台任务。具体步骤见[流量统计与异常消耗](../troubleshooting/traffic-usage.md)。
