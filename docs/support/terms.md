# 服务条款简要说明

本条款适用于 Paxora 提供的产品、网站和服务。购买或使用 Paxora 服务，即表示你已阅读并同意本页条款；如果不同意，请停止购买或使用相关服务。

1. 使用服务时，应遵守所在地、线路所在地以及适用的其他法律法规。
2. Paxora 不庇护违法犯罪行为，并可能依法配合有权机关的调查。
3. Paxora 提供中立的网络服务。用户个人行为产生的法律责任由用户自行承担。

2. 从事洗钱、诈骗或其他非法交易。
3. 发送垃圾邮件或批量骚扰信息。
4. 发起、转发或协助网络攻击。
5. 未经授权访问数据、系统、账号、主机或网络。
6. 干扰其他用户、服务、主机或网络的正常运行。
7. 传播病毒、蠕虫或其他恶意程序。
8. 规避主机、网络或账号的安全认证。
