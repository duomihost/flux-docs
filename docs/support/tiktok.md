# 关于 TikTok 的说明

部分用户希望通过节点访问 TikTok，但需要注意：

- Paxora 节点并非专门针对 TikTok 优化。
- 使用时可能出现不稳定、加载失败或黑屏。
- TikTok 的地区限制和检测策略可能随时变化，因此无法保证访问效果。

## 使用建议

以下方法来自用户反馈，仅供参考：

- 优先尝试标注为“家宽”或“住宅”的节点。
- 移动设备可以尝试移除 SIM 卡；iPad 通常受 SIM 卡影响较小。
- 使用非住宅节点时，可将设备语言、地区和时间设置为目标国家，并按需启用全局代理。
- 电脑端可以直接访问 [TikTok 网页版](https://www.tiktok.com/)测试。

:::warning
以上方法不保证有效。实际效果会受到设备、地区、网络和 TikTok 平台策略影响。
:::

## 技术支持与退款

- Paxora 暂无 TikTok 专属支持方案，不提供针对 TikTok 的连接调试。
- 因 TikTok 平台限制导致的访问异常，不作为服务退款依据。
- 如有专用节点等定制需求，可以通过用户中心提交工单，由工作人员评估可行性。
