# 官网地址与联系我们

## 官网及相关入口

- [用户中心](https://hi.dmhosts.com/)：推荐收藏，可自动跳转到可访问地址。
- [备用跳转入口](https://available-domains-detection-2t2.pages.dev/)：用户中心无法访问时使用。
- [永久域名](https://www.tabnet.us/)
- [通用域名](https://ls.tabnetservices.com/)
- [技术文档](https://doc.tabweb.us/)
- [服务条款](https://www.tabnet.us/tos.html)

域名可能因网络环境发生变化，建议保存至少两个入口。请核对网址，避免在仿冒网站输入账号和密码。

## 工单系统

工单主要处理账号、套餐和财务相关问题。

- 提交位置：登录用户中心，在侧边栏找到工单入口。
- 处理时效：通常在两个工作日内处理或回复。
- 提交内容：说明设备、系统、客户端、问题现象和已经尝试的步骤。

提交截图前，请遮住邮箱、订阅地址、订单信息和其他个人资料。

## 连接问题反馈模板

反馈无法连接、速度慢或特定网站访问异常时，建议按以下格式提供信息：

```text
设备与系统版本：
客户端名称与版本：
所在地区与运营商：
网络类型：家庭宽带 / 移动网络 / 公司或校园网络
节点名称与地区：
代理模式：规则 / 全局 / 其他（请说明）
受影响的网站或应用：
问题现象与错误提示：
发生时间与时区：
出现频率：持续发生 / 间歇发生（请说明频率）
已尝试的排查步骤及结果：
```

请尽量提供可复现的操作步骤，并说明问题影响单个节点、部分节点还是全部节点。对比不同节点或网络时，每次只改变一个条件，便于判断影响因素。

截图只需包含与问题有关的界面。提交前请遮住邮箱、个人订阅地址、二维码、验证码和订单支付信息；不要提交账号密码或完整配置文件。

## 在线客服

在线客服位于网站页面右下角，可用于其他一般问题。

- 在线时间：通常为 09:00–22:00。
- 离线时：请完整描述问题，客服会在后续统一回复。

## 备用域名和通知频道

其他备用域名包括：

- `dashboard.tabnetservices.com`
- `panel.tabnet.us`
- `x.tab-net.com`

通知及优惠信息也可能发布在 [Telegram 频道](https://t.me/tabnet3)，访问时可能需要可用的网络环境。

## 投诉、建议和滥用举报

可以通过用户中心菜单中的工单提交：

- **投诉建议**：说明具体问题和希望改进的内容。
- **报告滥用**：提供可核实的信息；确认滥用后，相关账号可能被限制或永久停用。

此类工单通常会在七个工作日内处理或回复。
