# 选择节点

## 根据使用场景选择

- 日常浏览：优先尝试推荐节点，再结合延迟和实际访问效果选择。
- 视频场景：选择与目标服务地区相符的节点，实际可用性以访问结果为准。
- 开发访问：选择稳定性更高的线路。
- 跨境办公：优先选择负载较低的节点。

如果某个节点临时不可用，请更新订阅后切换到其他节点。

## 了解节点信息

节点列表中可能显示以下信息，具体项目以当前客户端或用户中心为准：

| 信息 | 含义与选择建议 |
| --- | --- |
| 地区 | 用于判断目标服务的地区适配情况；不能仅凭地区名称判断速度。 |
| 倍率 | 影响套餐流量扣除量，使用前应查看节点标注及套餐说明。 |
| 等级或套餐权限 | 表示节点的使用范围，以当前账号实际可选节点为准。 |
| 速率限制 | 表示服务允许的最高速率，实际速度还受本地网络、线路负载和目标服务影响。 |
| 在线数或负载 | 用于辅助判断节点使用情况，不能单独作为速度或稳定性的保证。 |
| 住宅、原生或媒体等标签 | 用于描述线路特征或用途，不代表目标网站始终可用。 |

## 为什么不同账号或客户端的列表不一样

节点列表按当前账号的权限和节点的展示设置筛选，不是后台全部服务器的目录。节点自身的流量额度、客户端格式、协议选择或筛选条件也可能影响最终列表。比较时应使用同一账号、相近时间和相同客户端条件，不能把数量差异直接归因于订阅 01～04 的编号。

有些条目可能用于显示剩余流量、套餐到期或过滤提示，而不是新增的一条独立线路。提示条目可能复用已有节点的连接信息，不应把它单独统计为额外地区、节点池或流媒体解锁能力；套餐状态应到用户中心核对。

## 名称中的协议标记

如果当前节点名称带有下列前缀，可用于识别其协议；是否显示前缀以实际列表为准：

| 标记 | 协议名称 |
| --- | --- |
| `[ss]` | Shadowsocks |
| `[vmess]` | VMess |
| `[vless]` | VLESS |
| `[trojan]` | Trojan |
| `[Hy]` / `[Hy2]` | Hysteria / Hysteria 2 |
| `[tuic]` | TUIC |
| `[socks]` | SOCKS |
| `[anytls]` | AnyTLS |

这里只解释本地节点实现中的名称标记，不是现行协议开放清单，也不意味着任意客户端都兼容所有协议。协议名称不代表固定速度；无法导入或显示的节点应先核对[客户端与订阅格式](../subscription/import-subscription.md)。

## 节点倍率如何影响流量

若节点按倍率计费，可以按以下方式理解：

**套餐扣除流量 = 按服务规则统计的流量 × 节点倍率。**

例如，某节点标注为 `2×`，按服务规则统计的流量为 `1 GB` 时，对应扣除 `2 GB` 套餐流量。这只是计算示例，不代表当前节点的实际倍率。

上传、下载的统计范围及流量重置规则以当前套餐和用户中心说明为准。倍率反映计费规则，不能据此判断节点速度或质量；没有明确标注时，请先核实，不要自行假定为 `1×`。

节点如果配置了分时倍率，不同时间可能使用不同倍率，以当前显示和服务规则为准，不将旧截图或静态目录中的数值当作长期固定值。

## 延迟与实际速度

延迟反映连接响应时间，不等同于下载速度。比较节点时，尽量保持设备、网络、目标网站和测试时段一致，每次只切换一个节点。

能显示节点或测出延迟，也不能替代真实连接和目标服务访问的结果。连接失败时按[无法连接](../troubleshooting/cannot-connect.md)排查并反馈，不凭延迟结果推断账号已获得额外权限。

## 当前节点与解锁信息以哪里为准

本页说明节点信息的含义和选择方式，不提供未经核实的现行节点目录。具体公开名称、可用地区、当时倍率和适用套餐，以当前账号实际列表及用户中心说明为准。

媒体或住宅标签不是某个平台当前可解锁的证明；流媒体可用性需要带节点、目标平台、地区和时间的实际记录。没有这些依据时，不把标签或历史结果写成“已实测”或永久可用。

如果流量扣除与预期不一致，请参阅[流量显示异常](../troubleshooting/traffic-usage.md)。
