# 更新订阅

当节点列表为空、套餐刚刚更新或已有节点无法使用时，可以刷新客户端数据。

## Paxora 官方客户端

1. 先断开当前连接。
2. 确认账号已经登录且套餐有效。
3. 刷新节点列表；如果页面没有刷新按钮，退出 Paxora 后重新打开。
4. 等待客户端完成同步，再选择节点连接。

## 第三方客户端

1. 先断开当前连接。
2. 打开“订阅”或“配置”页面。
3. 选择已经导入的 Paxora 订阅。
4. 点击“更新”“刷新”或对应的下载按钮。
5. 返回节点列表并重新选择节点。

如果更新失败，先保留已有配置、手动规则和错误提示，再查看[订阅下载或更新失败](../troubleshooting/subscription-failed.md)。确认地址确实来自自己的用户中心、格式适合当前客户端，并且没有在重置订阅后继续使用旧地址。

确实需要更换地址时，优先编辑现有订阅的地址；也可以在客户端支持的情况下新建独立条目验证。确认新条目更新成功、节点正常后再处理旧条目，不要先删除原配置。含个人订阅地址的配置备份应妥善保存，不要随反馈一起上传。
