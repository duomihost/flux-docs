# 更新订阅

当节点列表为空、套餐刚刚更新或已有节点无法使用时，可以刷新客户端数据。

## Paxora 官方客户端

1. 先断开当前连接。
2. 确认账号已经登录且套餐有效。
3. 刷新节点列表；如果页面没有刷新按钮，退出 Paxora 后重新打开。
4. 等待客户端完成同步，再选择节点连接。

## 第三方客户端

1. 先断开当前连接。
2. 打开“订阅”或“配置”页面。
3. 选择已经导入的 Paxora 订阅。
4. 点击“更新”“刷新”或对应的下载按钮。
5. 返回节点列表并重新选择节点。

如果更新失败，请从 Paxora 用户中心重新复制个人订阅地址，然后删除旧配置并重新导入。
