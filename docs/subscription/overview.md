# 订阅概览

订阅用于同步节点、线路、套餐权限和连接配置。

## 使用 Paxora 官方客户端

登录 Paxora 后，客户端会自动同步账号中的套餐和节点。通常不需要复制或手动导入订阅链接。

## 使用第三方客户端

Shadowrocket、Clash Verge 等第三方客户端不能直接登录 Paxora，需要从 **Paxora 用户中心**复制个人订阅地址，再导入客户端。

第三方客户端由各自开发者维护，并非 Paxora 官方客户端。应用本身的安装、兼容性或收费问题，请以开发者说明为准。

## 订阅 01～04 有什么区别 {/* #numbered-addresses */}

用户中心“复制 / 导入订阅”页面中的编号用于选择订阅获取地址：

| 页面选项 | 含义 |
| --- | --- |
| 订阅 01 | 页面当前展示的主订阅地址。 |
| 订阅 02 | 当前备用地址列表中的第一个地址。 |
| 订阅 03 | 当前备用地址列表中的第二个地址。 |
| 订阅 04 | 当前备用地址列表中的第三个地址。 |

通常先选订阅 01。当前地址无法下载或更新时，可选择 02、03 或 04 中的一个备用地址重试；找到可用地址即可，不需要把四个地址全部导入。

这些地址使用同一账号的订阅凭据，进入同一订阅处理流程。账号的套餐权限不会因为选择了另一个编号而升级，也不会因此换到独立的节点池。更换获取入口不等于更换连接节点。

“订阅 01～04”和下方的“通用订阅 / iOS 订阅 / 路由器”是两层选择：先选获取地址，再按自己的客户端选择导入方式。不能把 01、02、03、04 分别对应到 Clash、Shadowrocket、Surge 或路由器。

:::info[编号说明的适用范围]
此说明依据 2026-10-17 已核实的用户中心资料，并与本地页面及订阅实现交叉核对。主、备用地址的顺序和数量可随后台配置调整，以用户中心当前显示为准；不把某个编号永久绑定到某个域名。不同客户端格式或 DNS 适配可能影响返回内容，不能保证四个地址的配置文本逐字相同。
:::

Shadowrocket 页面若显示“1 导入模块”“2 添加订阅”，请按顺序操作，先导入当前所选地址对应的模块，再添加订阅。没有模块步骤时按页面现有引导操作，不要自行拼接模块地址。详见[模块导入说明](./import-subscription.md#shadowrocket-module)。

## 订阅地址、节点、协议和速度的关系

订阅地址用于获取账号对应的节点和配置；节点是建立连接时选择的线路；协议是客户端与节点之间使用的连接方式。复制或更新订阅成功，不等于当前节点已经连接成功。

地址编号不表示协议、国家或地区、固定 Mbps、节点数量或套餐等级；这类信息应看当前账号的节点列表和套餐说明，不要自行替换订阅地址的域名或路径。

实际速度还受本地网络、线路负载和目标服务影响，不能根据订阅地址或协议名称作速度保证。选择节点及流量倍率见[节点选择说明](../nodes/choose-node.md)。
