# 导入订阅

Paxora 官方客户端登录后会自动同步节点，无需执行本页操作。本页仅适用于 Shadowrocket、Clash Verge 等第三方客户端。

## 先选择地址和导入方式

在用户中心打开“复制 / 导入订阅”，通常先选订阅 01；需要备用入口时再选 02、03 或 04。编号是[主、备用地址的展示顺序](./overview.md#numbered-addresses)，不是客户端或速度分类。随后选择通用订阅、iOS 订阅或路由器等适合自己客户端的导入方式。

## Shadowrocket 的模块步骤 {/* #shadowrocket-module */}

如果所选地址的 Shadowrocket 页面显示“1 导入模块”“2 添加订阅”：

1. 先点击“导入模块”，在 Shadowrocket 中按应用提示完成导入。
2. 返回用户中心，在同一所选地址下执行“添加订阅”或复制订阅地址。
3. 再按下方步骤添加订阅、更新节点和连接。

模块用于该订阅所需的 DNS 适配。只添加订阅而漏掉页面要求的模块，可能出现节点已显示但无法连接；模块下载失败时先按[订阅排障](../troubleshooting/subscription-failed.md)记录报错。没有显示模块步骤时，不要仅凭编号判断需要模块，也不要自行构造或索取他人的模块地址。

## 导入步骤

1. 打开 Paxora 用户中心并登录自己的账号。
2. 找到“订阅”或“一键订阅”。
3. 复制适合当前客户端的个人订阅地址；Shadowrocket 若显示模块步骤，先按上方说明完成模块导入。
4. 打开第三方客户端，进入“订阅”“配置”或“Profiles”。
5. 新建订阅，粘贴地址并保存。
6. 更新订阅，确认节点列表已经出现。
7. 选择一个节点并连接。

不同客户端的按钮名称可能不同，具体步骤请查看对应平台教程。

如果下载报错、格式不受支持，或更新成功后没有节点，请按[订阅下载或更新失败](../troubleshooting/subscription-failed.md)区分现象。先保留错误提示和已有配置，不要为反复导入而清空其他订阅。

:::danger
订阅地址只能供本人使用。不要将地址发送给他人，也不要在截图中显示完整内容。
:::
