# 订阅安全

个人订阅地址相当于账号访问凭据。请遵守以下原则：

- 不在公开网页、截图、聊天群或工单中展示完整地址。
- 不把订阅地址提交到 GitHub 或其他代码仓库。
- 只在可信设备和可信客户端中导入订阅。
- 不向陌生人提供账号、验证码或订阅地址。
- 发现泄露后及时重置订阅，并删除第三方客户端中的旧配置。

:::warning
从他人处获取的共享 Apple ID 不应登录 iCloud。安装 iOS 应用时，请优先使用自己的 App Store 账号。
:::
