# iPhone 与 iPad 使用说明

Paxora 暂未提供 iPhone 或 iPad 官方客户端。Apple 移动设备需要使用兼容的第三方客户端。

简单来说，你需要先安装 Shadowrocket，再从 Paxora 用户中心复制自己的订阅并导入。iPhone 和 iPad 不安装 Paxora 安装包。

## 推荐客户端：Shadowrocket

付费 App Store 客户端，功能成熟，适合希望使用常见订阅方式的用户。

[查看 Shadowrocket 教程](../third-party/ios-shadowrocket)

## 使用流程

基本步骤如下：

1. 从 App Store 安装客户端。
2. 登录 Paxora 用户中心并复制个人订阅地址。
3. 在客户端内导入订阅。
4. 选择节点。
5. 首次连接时允许系统添加 VPN 配置。

:::danger
不要使用陌生人提供的共享 Apple ID 登录 iCloud。切换 App Store 账号也应谨慎，避免个人资料泄露或设备被锁定。
:::
