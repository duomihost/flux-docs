# Android 安装与使用 Paxora

本教程适用于 Android 和兼容 Android 应用的 HarmonyOS 手机、平板。

## 先看完整流程

**下载 APK → 允许本次安装 → 登录 → 等待节点加载 → 选择节点 → 允许 VPN 请求。**

看到 Paxora 显示连接成功，或手机状态栏出现 VPN 标志后，再打开浏览器测试网页。

## 使用要求

- Android 9 或更高版本
- 可用的 Paxora 账号

## 下载与安装

1. 点击上方“Android 主下载”获取 `.apk` 安装包。主下载无法打开时，再使用备用下载目录选择 Android 安装包。
2. 打开下载的文件并确认安装。
3. 如果系统阻止安装，按照提示允许浏览器或文件管理器“安装未知应用”。
4. 安装完成后立即关闭该授权。

:::warning
不同品牌手机的菜单名称可能不同。只对本次使用的官方安装包授权，不要长期开放未知应用安装权限。
:::

## 登录账号

打开 Paxora，输入注册邮箱和密码登录。第一次登录会同步订阅和节点，可能需要稍等片刻。

登录后会自动加载账号和节点。加载期间不要连续点击连接按钮。

节点加载完成后，首页会显示可连接状态。

如果长时间没有加载出节点，请完全退出 Paxora 后重新打开。

## 选择并连接节点

1. 从节点列表选择需要的国家或地区。
2. 点击一个可用节点。
3. 点击“连接”。
4. 首次连接时，系统会请求创建 VPN 连接，请选择“允许”。
5. 等待 Paxora 显示连接成功。

首次出现 VPN 连接请求时必须点击“确定”或“允许”，否则客户端无法连接。

连接成功后打开浏览器测试网络。不再使用时返回 Paxora 点击“断开连接”。

## 后台运行

部分手机会限制后台应用。连接容易中断时，请允许 Paxora 后台运行，并在系统电池设置中取消对 Paxora 的省电限制。
