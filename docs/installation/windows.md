# Windows 安装与使用 Paxora

## 先看完整流程

**下载 Paxora → 安装并登录 → 选择节点 → 点击连接。**

连接成功后，Paxora 会显示已连接状态。此时打开浏览器测试网页即可；不用时请先在 Paxora 中断开连接。

## 使用要求

- Windows 10 或 Windows 11
- 可用的 Paxora 账号

## 下载与安装

1. 点击上方“Windows 主下载”获取 `.exe` 安装包。主下载无法打开时，再使用备用下载目录选择 Windows 安装包。
2. 双击安装包，按照向导完成安装。
3. 安装完成后启动 Paxora。

如果 Windows 显示“已保护你的电脑”，请先确认文件来自上面的官方下载目录，再点击“更多信息 → 仍要运行”。

使用备用下载目录时，将鼠标移到 Windows 安装包上，点击出现的下载按钮。

如果浏览器提示“此文件通常不会下载”，请先确认网址是 Paxora 官方下载地址，再选择保留文件。

:::warning
部分安全软件可能误拦截网络工具。只有在确认安装包来自官方目录后，才可以临时允许安装；安装完成后应重新启用安全防护。
:::

## 登录账号

1. 输入在 Paxora 注册的邮箱和密码。
2. 点击“登录”。
3. 等待客户端同步套餐和节点。

登录成功后，点击首页的“切换”进入节点列表。

## 选择并连接节点

1. 点击“切换”或打开节点列表。
2. 选择需要的国家或地区。
3. 选中一个延迟较低的节点。
4. 返回首页，点击“连接”。
5. 等待客户端显示连接成功。

连接成功后打开浏览器测试网络。不再使用时返回 Paxora 点击“断开连接”，再退出客户端。

## 无法连接

先尝试更换节点、退出其他代理软件并重新启动 Paxora。如果仍然失败，请查看[无法连接排查](../troubleshooting/cannot-connect)。
