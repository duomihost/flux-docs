# Paxora 使用文档

这里提供 Paxora 客户端的下载、安装和使用说明，以及暂未提供官方客户端的平台所需的第三方客户端教程。

:::info[关于教程图片]
部分步骤图迁移自旧版教程，可能显示旧版界面或历史名称。当前产品名称统一为 **Paxora**；操作时请寻找图片中对应的同名按钮，具体位置以当前客户端为准。
:::

## 应该使用哪个客户端？

| 设备 | 推荐客户端 | 类型 |
| --- | --- | --- |
| Windows 10 / 11 | Paxora | 官方客户端 |
| macOS | Paxora | 官方客户端 |
| Android / HarmonyOS | Paxora | 官方客户端 |
| iPhone / iPad | Shadowrocket | 第三方客户端 |

如果你的设备支持 Paxora，请优先使用 Paxora。官方客户端登录账号后会自动获取套餐和节点，不需要手动复制订阅链接。
