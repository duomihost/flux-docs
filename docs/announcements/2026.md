# 2026年公告和日志

## 关于近期异常问题公告

**2026.08.28**

近期因入口服务器资源异常，部分用户可能出现速率下降、连接超时、连接不稳定或无法使用等情况。对此给您带来的不便，我们深表歉意，目前正在持续进行资源调整与线路优化。

同时建议优先使用官方客户端；第三方客户端用户请及时更新订阅并重新连接或切换线路。

发生大规模或集中性故障时，由于短时间内同类咨询较多，客服可能无法逐一回复，相关处理进展将统一通过本页公告同步，请您留意最新通知。待服务恢复稳定后，我们将根据实际影响情况评估相应补偿。

**2026.08.04**

目前，联通及移动网络已陆续恢复。使用联通或移动网络的用户，请更新订阅并重新导入配置后尝试连接。

**2026.08.02**

近期，部分用户出现无法正常使用、连接异常等问题。目前我们已锁定问题原因，技术团队正在持续跟进并全力排查处理。后续处理进展及服务恢复情况将通过本页公告及时发布。
